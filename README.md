# hse-minor-octopus-sinensis

В качестве объекта исследования был выбран восточноазиатский осьминог Octopus sinensis — представитель семейства Octopodidae, распространённый в прибрежных водах Восточной Азии. Для анализа использовалась хромосомная сборка генома GCF_006345805.1 (ASM634580v1), содержащая 30 групп сцепления (linkage groups).

В рамках проекта были проанализированы вторичные структуры ДНК и эпигенетические регуляторы генома. Поиск потенциальных G-квадруплексов выполнялся по регулярному выражению (G{3,5}[ATGC]{1,7}){3,}G{3,5} на обеих цепях ДНК. Предсказание участков Z-ДНК проводилось с использованием программы Z-Hunt с последующей фильтрацией результатов по пороговому значению Z-score > 400.

Дополнительно был выполнен анализ промоторных регионов генов и поиск участков Z-ДНК в промоторах. Среди генов, ассоциированных с Z-ДНК в промоторных областях, были обнаружены регуляторные белки, включая ATF-4 и представителей семейства histone H2A-like. Полученные результаты использовались для дальнейшего сравнительного анализа с другими видами головоногих моллюсков.

## Поиск генов, связанных с эпигенетикой

Для поиска генов, связанных с эпигенетической регуляцией, был использован HMMER 3.3.2 и база Pfam 35.0. Были выбраны домены, соответствующие белкам метилирования ДНК, модификации гистонов и ремоделирования хроматина.

Первичный поиск по 11 Pfam-доменам выявил 1050 доменных совпадений. Большое число результатов связано с тем, что некоторые домены (например, PHD и Helicase_C) встречаются во многих белках и не всегда являются специфичными для эпигенетической регуляции. После удаления изоформ, низкокачественных белков и фильтрации по функциональной аннотации было получено 26 уникальных генов-кандидатов.

Для каждого выбранного эпигенетического семейства был определён соответствующий Pfam-домен. Далее все выбранные домены были объединены в набор HMM-профилей и использованы для поиска по протеому Octopus sinensis с помощью HMMER.

## Поиск вторичных структур ДНК

### Поиск G-квадруплексов

Поиск потенциальных G-квадруплексов выполнялся по регулярному выражению `(G{3,5}[ATGC]{1,7}){3,}G{3,5}` на обеих цепях ДНК. Анализ проводился для 30 основных linkage groups сборки *Octopus sinensis* GCF_006345805.1.

Всего было найдено 62 964 потенциальных G-квадруплекса.

### Поиск Z-ДНК

Поиск потенциальных участков Z-ДНК выполнялся с использованием алгоритма Z-Hunt [Z-DNA hunter](https://bioinformatics.ibp.cz) для 30 основных linkage groups сборки *Octopus sinensis* GCF_006345805.1. Unplaced scaffolds на данном этапе не анализировались.

Всего по 30 linkage groups было получено 1 605 859 предсказаний Z-ДНК. Для дальнейшего анализа использовалась фильтрация по пороговому значению SCORE > 400, после которой осталось 539 высокодостоверных предсказаний.

Для групповой части проекта дополнительно был выполнен поиск участков Z-ДНК в промоторных областях генов. Промотор определялся как участок длиной 2000 п.н. upstream от точки начала транскрипции (TSS). Без фильтрации по SCORE было обнаружено 17 919 пересечений с промоторными регионами, после фильтрации SCORE > 400 осталось 12 попаданий.
